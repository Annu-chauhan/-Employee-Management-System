# Employee Management System

A console-based Employee Management System developed using Core Java, JDBC, and MySQL.

## Features
- Add Employee
- View Employees
- Search Employee
- Delete Employee
- Employee Count Tracking
- MySQL Database Connectivity
- Input Validation

## Technologies Used
- Java
- JDBC
- MySQL
- SQL
- VS Code

## Project Description

This project is developed to manage employee records using Java and MySQL database integration. The application performs CRUD operations such as adding, viewing, searching, and deleting employee details.

JDBC connectivity is used to establish communication between Java application and MySQL database. The project follows object-oriented programming concepts and uses SQL queries for database operations.

The application provides a menu-driven console interface with real-time database updates and employee record management functionality.
